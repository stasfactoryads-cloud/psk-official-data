# PSK Official Data

Единый источник правды по проектам ГК ПСК. Агенты и скрипты аудита читают данные из `api/projects.json`.

## Структура

- `projects/<slug>.json` — один файл на проект. Правится вручную или скриптом.
- `api/projects.json` — собранный файл со всеми проектами. Не править руками, создаётся `build.py`.
- `build.py` — проверяет файлы проектов и собирает `api/projects.json`.

## Формат поля

Ключевые данные хранятся с источником и датой проверки:

```json
"min_price": {"value": 5874072, "source": "psk-info-api", "checked": "2026-10-20", "status": "partial"}
```

Статусы: `verified` (подтверждено), `partial` (подтверждено частично), `unverified` (не подтверждено), `mismatch` (расхождение с сайтом), `no_dates` (нет дат акции).

## Приоритет источников

1. `manual_overrides` — данные от отдела продаж. Всегда важнее автоматических.
2. `psk-info-api` и открытые источники.
3. Сайты проектов — только для сверки, не источник значений.

## Обновление

- Отдел продаж присылает файл (скидки, акции, условия) — правка в `projects/` или в `manual_overrides`.
- Раз в сутки задача сверяет открытые источники и обновляет `checked`.
- Затем запускается `build.py`, и изменения уходят в git.
